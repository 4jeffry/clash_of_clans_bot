## Quick Start
- Backend: `cd ~/clan-bot && python run_all.py`
- Frontend: `cd ~/niki-bot-web && npm run dev`
- Database: Supabase (PostgreSQL)
- Hosting: Railway (backend) + Vercel (frontend)
