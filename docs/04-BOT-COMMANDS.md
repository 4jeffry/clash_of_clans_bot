# Bot Discord Commands

Semua command slash (`/`). Sebagian fitur dikunci per tier.

## Setup & Umum

- `/setup` - Hubungkan server Discord dengan klan CoC
- `/help` - List command
- `/clanmembers` - Demografi TH & roster
- `/thcomposition` - Breakdown TH

## War

- `/warstatus` - Status war aktif
- `/cwl` - Info CWL
- `/racewar` - Race war
- `/recap-war` - Rekap war terakhir
- `/recap-cwl` - Rekap CWL

## Members

- `/donations` - Top donatur
- `/inactive` - Member pasif
- `/leaderboard` - Leaderboard
- `/compare` - Bandingkan member
- `/rewards` - Reward management

## Capital (Raid Weekend)

- `/capital` - Info raid
- `/capitaldonations` - Top kontributor

## AI (Tier PRO)

- `/ai audit` - Audit klan
- `/ai screen` - Screen calon member
- `/ai opponent` - Analisis lawan
- `/ai scout` - Scout war
- `/ai strategy` - Strategi war
- `/ai report` - Report pasca war
